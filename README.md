# y-music-blind

**y-music-blind** — это десктопный клиент для прослушивания и скачивания музыки с Яндекс.Музыки, оптимизированный для работы с программами экранного доступа (NVDA, Screen Reader и т.д.). Интерфейс построен на wxPython.

## Функционал

### Поиск
- Поиск **треков**, **исполнителей**, **альбомов**, **подкастов** и **выпусков подкастов** через строку поиска
- Пагинация: кнопка «Загрузить ещё» подгружает следующую страницу результатов

### Просмотр
- **Треки исполнителя** — загрузка популярных треков выбранного исполнителя
- **Альбомы исполнителя** — просмотр альбомов с возможностью открыть любой альбом и увидеть его треки
- **Треки жанра** — параллельная загрузка через ротор Яндекс.Музыки (12 потоков) для быстрой случайной выборки
- **Треки альбома** — раскрытие альбома с треками по дискам (volumes)
- **Плейлисты** — просмотр пользовательских плейлистов, управление ими и их треками
- **Персональные плейлисты** — быстрый доступ к персональным подборкам («Плейлист дня», «Тайник», «Премьера», «Дежавю», «Подкасты недели», «Плейлист с Алисой»)

### Воспроизведение
- Потоковое воспроизведение через BASS audio library (`bass.dll`)
- Поддержка эффектов BASS_FX (`bass_fx.dll`): настоящий 5-полосный эквалайзер с пресетами («Поп», «Рок», «Техно», «Софт-рок», «Классика», «Электронная», «Клубная вечеринка») и изменение темпа/скорости без изменения тона (от 0.25x до 3.0x, шаг 0.05)
- Переключение аудиоустройств вывода на лету (`Ctrl+D` / меню плеера)
- Управление эквалайзером (`Ctrl+U` / меню плеера)
- Пауза / возобновление (`Пробел` в диалогах / `F7`)
- Перемотка ±5 сек (`Ctrl+F7`/`Ctrl+F8`) и ±10 сек (`Shift+F7`/`Shift+F8`)
- Регулировка громкости (`Ctrl+↑`/`↓` или `F5`/`F6`), шаг 10%
- Автоматическое воспроизведение следующего трека по окончании текущего
- **Повтор трека** (`Ctrl+R`) — при окончании текущий трек запускается заново
- **Перемешивание (Shuffle)** (`Ctrl+J`) — случайный порядок воспроизведения треков в списке
- **Информация об очереди** (`Ctrl+K`) — озвучивание позиции текущего трека в очереди
- Открытие трека, альбома, плейлиста или исполнителя в системном плеере через временный M3U-файл (`Ctrl+O`)

### Скачивание
- Скачивание отдельного трека в MP3 (`Ctrl+S`) с индикацией прогресса
- **Скачивание плейлистов и альбомов в ZIP-архив** (`Ctrl+S` на плейлисте/альбоме) с сохранением тегов и структуры
- Выбор директории для загрузок в настройках
- Опциональное диалоговое окно по завершении с возможностью открыть папку

### Оценки и плейлисты
- Лайк / дизлайк трека, альбома и плейлиста (`Ctrl+L` / `Shift+L`)
- Добавление треков в пользовательские плейлисты
- Управление видимостью плейлистов (публичный / приватный), изменение описания и просмотр трейлеров
- Рекомендации и похожие сущности для плейлистов

### Менеджер аккаунтов (`Ctrl+M`)
- Добавление, переключение, редактирование и удаление учётных записей
- Три способа авторизации:
  1. **Код устройства** — получение кода и ввод на yandex.ru/device (или через встроенный браузер с поддержкой F5 для обновления)
  2. **Веб-перехват (классический)** — OAuth через WebView с перехватом `access_token` из URL
  3. **Ручной ввод токена** — если токен уже есть
- Изоляция кук-сессии для каждой авторизации (через временные папки WebView2)
- Копирование токена в буфер обмена (контекстное меню)
- Автоматическая авторизация при запуске

### Настройки (`Ctrl+P`)
- **Общие**: папка загрузок, подробные ошибки, диалог после загрузки, запоминание позиции курсора, проверка обновлений при старте, отображение альбома в списке треков, сворачивание в системный трей (`minimize_to_tray`), отображение названия трека в значке трея (`tray_show_track_name`), уровень логирования, очистка логов при старте
- **Речь**: включение/отключение речевого вывода, использование SAPI5, озвучивание статуса плеера и общих событий
- **Вид**: темная тема, размер шрифта в пунктах, формат времени (`short` / `full`)

### Речевой вывод
- Озвучивание через **NVDA Controller Client** (`nvdaControllerClient64.dll`)
- Фолбэк на **SAPI5** (через win32com)
- Настройка категорий: статус плеера и общие события включаются отдельно
- Прерывание речи по Ctrl
- Асинхронное произношение в фоновом потоке с антифлудом (дебаунсом)

### Автообновление
- Интегрированный модуль автообновления (`app_updater.py` и автономный `updater.exe`)
- Проверка свежих релизов через GitHub API с показом списка изменений (changelog)
- Скачивание обновления с индикацией прогресса, скорости (МБ/с) и оставшегося времени (ETA)
- Выборочная распаковка архива с сохранением пользовательских настроек (файлов конфигурации и аккаунтов) и перезапуском приложения

### Звуковые события
- Подключение (`connect.wav`)
- Ошибка (`error.wav`)
- Завершение загрузки (`complete_download.wav`)

## Установка и запуск из исходного кода

### Системные требования

- **OS**: Windows 10/11 (x64)
- **Python**: 3.12.10 (x64) — *рекомендуется, проект тестировался на этой версии*
- **Screen Reader** (опционально): NVDA 2024+

### 1. Установка Python-зависимостей

```bash
pip install -r requirements.txt
```

**Важно:** `wxPython==4.2.5` требует совместимой версии Python и Visual C++ Redistributable. Если pip не может найти wheel, скачайте вручную с [PyPI](https://pypi.org/project/wxPython/4.2.5/) под вашу версию Python и ОС.

### 2. Зависимости, которых нет в pip

Эти файлы необходимо скачать и разместить вручную в соответствующих папках проекта.

#### BASS Audio Library (`bass.dll`) и `bass_fx.dll`

**Где взять:** https://www.un4seen.com/bass.html и https://www.un4seen.com/

- Скачайте **BASS for Windows** и **BASS_FX**
- Извлеките `x64/bass.dll` и `x64/bass_fx.dll` в корень проекта (`y-music-blind/`)
- **Важно:** нужны именно 64-битные версии (из папки `x64` в архивах)

#### NVDA Controller Client (`speech/nvdaControllerClient64.dll`)

**Где взять:** https://github.com/nvaccess/nvda/releases

- DLL находится в дистрибутиве NVDA (`/lib/2024.1/` или аналогично)
- Скопируйте `nvdaControllerClient64.dll` в папку `speech/` проекта
- Если DLL отсутствует, программа использует SAPI5 как запасной вариант

### 3. Запуск

```bash
python main.py
```

## Сборка бинарника (EXE) через PyInstaller

### Подготовка

1. Установите PyInstaller (уже есть в requirements.txt):
   ```bash
   pip install pyinstaller
   ```

2. Убедитесь, что все ресурсы на месте:
   - `bass.dll`, `bass_fx.dll` — в корне проекта
   - `speech/nvdaControllerClient64.dll` — в папке `speech/`
   - `sounds/*.wav` — звуковые файлы
   - `dox/help.txt`, `dox/keyboard.txt`, `dox/license.txt`, `dox/docs_version.txt` — документация

### Сборка

```bash
python -m PyInstaller Y-music-blind.spec
```

Или через `.cmd`-файл (выведет лог в `pyinstaller_log.txt`):

```cmd
pyinstaller.cmd
```

Готовый EXE появится в папке `dist/Y-music-blind/`.

### Структура ресурсов в сборке

Ресурсы подключаются через `--add-data`:
```
--add-data "sounds;sounds"
--add-data "dox;dox"
--add-data "bass.dll;."
--add-data "bass_fx.dll;."
```

│   ├── connect.wav

│   ├── help.txt
│   ├── keyboard.txt

│   └── docs_version.txt

├── requirements.txt        # Python-зависимости
