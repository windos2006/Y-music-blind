# y-music-blind

**y-music-blind** — это десктопный клиент для прослушивания и скачивания музыки с Яндекс.Музыки, оптимизированный для работы с программами экранного доступа (NVDA, Screen Reader и т.д.). Интерфейс построен на wxPython.

## Функционал

### Поиск
- Поиск **треков**, **исполнителей** и **жанров** через строку поиска
- Пагинация: кнопка «Загрузить ещё» подгружает следующую страницу результатов

### Просмотр
- **Треки исполнителя** — загрузка популярных треков выбранного исполнителя
- **Альбомы исполнителя** — просмотр альбомов с возможностью открыть любой альбом и увидеть его треки
- **Треки жанра** — параллельная загрузка через ротор Яндекс.Музыки (12 потоков) для быстрой случайной выборки
- **Треки альбома** — раскрытие альбома с треками по дискам (volumes)

### Воспроизведение
- Потоковое воспроизведение через BASS audio library (bass.dll)
- Пауза / возобновление (пробел)
- Перемотка ±5 сек (Ctrl+←/→) и ±10 сек (Shift+←/→)
- Регулировка громкости (Ctrl+↑/↓), шаг 10%
- Автоматическое воспроизведение следующего трека по окончании текущего
- **Повтор трека** (Ctrl+R) — при окончании текущий трек запускается заново
- Открытие трека в системном плеере через временный M3U-файл (Ctrl+O)

### Скачивание
- Скачивание трека в MP3 (Ctrl+S) с прогресс-баром
- Выбор директории для загрузок в настройках
- Опциональное диалоговое окно по завершении с возможностью открыть папку

### Оценки
- Лайк / дизлайк трека (Ctrl+L / Shift+L)
- Лайк / дизлайк альбома (Ctrl+L / Shift+L)

### Менеджер аккаунтов (Ctrl+M)
- Добавление, переключение, редактирование и удаление учётных записей
- Три способа авторизации:
  1. **Код устройства** — получение кода и ввод на yandex.ru/device (или через встроенный браузер)
  2. **Веб-перехват (классический)** — OAuth через WebView с перехватом `access_token` из URL
  3. **Ручной ввод токена** — если токен уже есть
- Изоляция кук-сессии для каждой авторизации (через временные папки WebView2)
- Копирование токена в буфер обмена (контекстное меню)
- Автоматическая авторизация при запуске

### Настройки (Ctrl+P)
- **Общие**: папка загрузок, подробные ошибки, диалог после загрузки, запоминание позиции курсора, уровень логирования, очистка логов при старте
- **Речь**: включение/отключение речевого вывода, использование SAPI5, озвучивание статуса плеера и общих событий

### Речевой вывод
- Озвучивание через **NVDA Controller Client** (nvdaControllerClient64.dll)
- Фолбэк на **SAPI5** (через win32com)
- Настройка категорий: статус плеера и общие события включаются отдельно
- Прерывание речи по Ctrl
- Асинхронное произношение в фоновом потоке

### Звуковые события
- Подключение (connect.wav)
- Ошибка (error.wav)
- Завершение загрузки (complete_download.wav)

## Установка и запуск из исходного кода

### Системные требования

- **OS**: Windows 10/11 (x64)
- **Python**: 3.12.10 (x64) — *рекомендуется, проект тестировался на этой версии*
- **Screen Reader** (опционально): NVDA 2024+

### 1. Установка Python-зависимостей

```bash
pip install -r requirements.txt
```

**Важно:** `wxPython==4.2.5` требует совместимой версии Python и Visual C++ Redistributable. Если pip не может найти wheel, скачайте вручную с [PyPI](https://pypi.org/project/wxPython/4.2.5/) под вашу версию Python и ОС.

### 2. Зависимости, которых нет в pip

Эти файлы необходимо скачать и разместить вручную в соответствующих папках проекта.

#### BASS Audio Library (`bass.dll`)

**Где взять:** https://www.un4seen.com/bass.html

- Скачайте **BASS for Windows**
- Извлеките `x64/bass.dll` в корень проекта (`y-music-blind/bass.dll`)
- **Важно:** нужна именно 64-битная версия (из папки `x64` в архиве BASS)

#### NVDA Controller Client (`speech/nvdaControllerClient64.dll`)

**Где взять:** https://github.com/nvaccess/nvda/releases

- DLL находится в дистрибутиве NVDA (`/lib/2024.1/` или аналогично)
- Скопируйте `nvdaControllerClient64.dll` в папку `speech/` проекта
- Если DLL отсутствует, программа использует SAPI5 как запасной вариант

### 3. Запуск

```bash
python main.py
```

## Сборка бинарника (EXE) через PyInstaller

### Подготовка

1. Установите PyInstaller (уже есть в requirements.txt):
   ```bash
   pip install pyinstaller
   ```

2. Убедитесь, что все ресурсы на месте:
   - `bass.dll` — в корне проекта
   - `speech/nvdaControllerClient64.dll` — в папке `speech/`
   - `sounds/*.wav` — звуковые файлы
   - `dox/help.txt` и `dox/license.txt` — документация

### Сборка

```bash
python -m PyInstaller Y-music-blind.spec
```

Или через `.cmd`-файл (выведет лог в `pyinstaller_log.txt`):

```cmd
pyinstaller.cmd
```

Готовый EXE появится в папке `dist/Y-music-blind/`.

### Структура ресурсов в сборке

Ресурсы подключаются через `--add-data`:
```
--add-data "sounds;sounds"
--add-data "dox;dox"
--add-data "bass.dll;."
```

Если собираете без `.spec`-файла, команда:

```bash
python -m PyInstaller ^
  --add-data "sounds;sounds" ^
  --add-data "dox;dox" ^
  --add-data "bass.dll;." ^
  --windowed ^
  --name "Y-music-blind" ^
  main.py
```

## Структура проекта

```
y-music-blind/
├── main.py                 # Точка входа, основной GUI (wxPython)
├── yandex_api.py           # Обёртка над yandex-music API
├── bass_player.py          # Воспроизведение через BASS (ctypes)
├── account_manager.py      # Менеджер учётных записей
├── oauth_webview.py        # OAuth через WebView
├── config_manager.py       # Настройки (config.json)
├── speech.py               # Речевой вывод (NVDA + SAPI5)
├── logger.py               # Инициализация логирования
├── utils.py                # Вспомогательные утилиты (get_resource_path)
├── exceptions.py           # Пользовательские исключения
├── version.py              # Номер версии
│
├── bass.dll                # BASS audio library (не в pip)
├── speech/
│   └── nvdaControllerClient64.dll  # NVDA Controller (не в pip)
├── sounds/
│   ├── connect.wav
│   ├── error.wav
│   └── complete_download.wav
├── dox/
│   ├── help.txt
│   └── license.txt
│
├── requirements.txt        # Python-зависимости
├── pyinstaller.cmd         # Скрипт сборки EXE
└── README.md
```
